# Power BI Supply Chain Dashboard

## Project Overview
This project analyzes supply chain performance using the DataCo Supply Chain dataset with more than 180,000 records.

The dashboard was built in Power BI and focuses on sales, profitability, delivery performance, product performance, geographic analysis, and monthly trends.

## Dashboard Pages
- Overview
- Delivery
- Product
- Geography
- Monthly Trends

## Key KPIs
- Total Sales
- Total Orders
- Total Quantity
- Total Profit
- Profit Margin %
- Average Order Value
- Late Delivery %
- Average Shipping Days
- Shipping Delay Days

## Tools Used
- Power BI
- Power Query
- DAX
- CSV Data Integration

## Data Preparation
The raw dataset was cleaned and transformed in Power Query before being used for analysis and reporting.
